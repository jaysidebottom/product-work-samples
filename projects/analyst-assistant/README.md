# Analyst Assistant

**Personal work sample · Product concept and interface mockups**

This concept explores an AI-assisted analysis workflow in which an analyst can clarify a question, review a plan, examine partial evidence, and share an analysis graph. The work emphasizes reviewable steps and visible uncertainty.

## Read the work

1. [Product requirements](prd.md): problem framing, intended users, workflow, scope, and proposed measures.
2. [Four annotated mockups](mockups/README.md): clarification, plan review, partial evidence, and graph sharing.
3. [Model integration notes](model-integration.md): the relationship between the proposed interface and its AI integration needs.

The [standalone PRD](docs/analyst-assistant.html) embeds the concept screens. The [mockup gallery](mockups/index.html) can be downloaded and opened locally; GitHub displays HTML source rather than hosting these pages.

## Evidence boundary

These are conceptual designs, not a functioning analyst application or evidence of validated customer outcomes. The mockups illustrate intended interactions; proposed metrics remain hypotheses.
